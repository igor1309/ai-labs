# cairana

Landing page: index.html

AI assistant for psychologists.

## Description

Cairana helps psychologists turn sessions into structured notes, working context, and next steps. It is positioned as a professional assistant — *not* an autonomous therapist, diagnostic system, or clinical decision-maker. The psychologist reviews, edits, and stays responsible for the clinical record. Working name; currently in the research and naming-validation stage.

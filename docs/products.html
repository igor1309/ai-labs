Web Apps

Agonara

Structured learning program environment with curated programs, learner progression, and evidence of mastery. Helps curators assemble and maintain learning programs from trusted sources, while learners progress through them with clear sequence, checkpoints, and evidence of mastery. AI assists program construction and learning support but does not own the curriculum.

Clipdeck

iPhone copy library for private prompts and skills. A minimal webpage backed by a serverless endpoint that reads a private GitHub repo and returns sanitized, normalized items — one tap copies the body without YAML front matter. Deployed at clipdeck.enoa.ai behind Cloudflare Access; supports plain-text and Markdown prompts.

TypeScript Cloudflare Worker Cloudflare Access Vitest
Nexum

Private repo memory system. Save GitHub repos with personal notes, search and sort the collection, keep metadata current. Full Swift stack — Hummingbird backend, Swift-to-Wasm web UI via JavaScriptKit.

Oracle — Am I Done?

"Oracle — Am I Done?" One-shot career outlook tool. Enter a profession and get a structured AI-generated assessment: risk timeline, key threats, recommended next steps, and a confidence rating. No chat, no accounts — just a single question and a clear answer.

Corpus Scout

Lexical search over a local text corpus. A read-only MCP server with two tools — pattern search and section reading over Markdown files. Powered by ripgrep, deterministic and stateless: no embeddings, no indexing, no mutation.

Node.js MCP ripgrep
Web Scout

SearXNG search for Claude Code. An MCP stdio server that exposes web search as a tool — runs locally, connects to a self-hosted SearXNG instance, and returns structured JSON results with per-call logging.

Services

Claude Insights

Weekly Claude Code usage reports. Aggregates local session data into metrics — sessions, code churn, tool usage, goals, friction points — then pushes to Supabase and notifies via Telegram.

Python Supabase Edge Functions Telegram Bot Nomos
Loki

Centralized logging stack. Grafana + Loki + Alloy on a VPS — collects Docker container logs and journald units, with label-bounded cardinality enforced by allowlists and CI checks.

Grafana Loki Alloy Docker Compose Cloudflare Tunnel
Nomos

AI sovereignty layer. A unified proxy between projects and LLM providers — vendor abstraction, per-project budget limits, token usage logging, and basic prompt injection safeguards. No cloud vendor lock-in, just a single Docker service with SQLite.

Node.js Express SQLite Docker Caddy VPS
Notio

Personal capture service. Send a link or a note from Telegram and it lands in a persistent inbox. The core is ingress- and storage-agnostic — Telegram is just one input, Supabase just one backend. Links get lightweight, non-AI enrichment (titles, GitHub repo metadata) before persistence.

# ADR Structure Template (Progressive Disclosure)

Each ADR should follow exactly this structure:

1. Executive Summary (≤ 10 lines)
	•	What is decided
	•	Why at high level
	•	Scope boundary

2. Context
	•	Problem being solved
	•	Constraints
	•	Rejected alternatives (brief)

3. Decision
	•	Precise normative statement
	•	Non-ambiguous invariants

4. Rules / Invariants
	•	Enforceable statements
	•	File names
	•	Tag patterns
	•	CI expectations
	•	“MUST / MUST NOT” language

5. Consequences
	•	Operational impact
	•	Tradeoffs accepted
	•	Future extension points

6. Non-Goals
	•	Explicit exclusions to prevent scope creep

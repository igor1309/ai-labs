# Job Search Strategy Toolkit

This skill provides comprehensive tools and strategies for strategic job searching, from deep job posting analysis to creative outreach methods that help candidates stand out.

## Quick Start

**Announce:** "I'm using the Job Search Strategy Toolkit to analyze this opportunity and develop a targeted approach."

When a user provides a job posting or asks for job search help, follow this workflow:

1. **Analyze the job posting** for both obvious and hidden requirements
2. **Interview the candidate** to uncover relevant skills and experiences
3. **Identify skill gaps** and provide development strategies
4. **Research the company** and identify strategic advantages
5. **Create a customized application strategy** that helps them stand out

## Core Functionality

### Job Posting Analysis

Extract insights from job postings using the analysis script:

```bash
# Analyze a job posting for insights
python scripts/analyze_job_posting.py job_posting.txt
```

This reveals:
- Technical and soft skill requirements
- Company culture signals
- Hidden opportunities and red flags
- Strategic recommendations for positioning

### Candidate Skill Discovery

Generate targeted interview questions to uncover candidate's relevant qualifications:

```bash
# Generate interview questions based on job analysis
python scripts/generate_interview_questions.py job_analysis.json
```

The script creates questions for:
- Technical skill validation
- Soft skill discovery
- Experience verification
- Culture fit assessment
- Hidden qualification discovery

### Strategic Research and Outreach

For company research and creative outreach strategies, reference the detailed guides that cover:
- Deep company intelligence gathering
- LinkedIn advanced search strategies
- Creative application formats
- Social media positioning
- Unconventional outreach methods

## Workflows

### Complete Job Application Strategy

1. **Analyze the Opportunity**
   - Run `analyze_job_posting.py` on the job description
   - Review company culture signals and hidden insights
   - Identify key requirements and nice-to-haves

2. **Assess Candidate Fit**
   - Use questions from `generate_interview_questions.py`
   - Map candidate's experience to requirements
   - Identify transferable skills and unique advantages

3. **Address Skill Gaps**
   - If gaps exist, reference `skill_development.md`
   - Create 30-day skill sprint plan
   - Identify quick credibility builders

4. **Research and Network**
   - Reference `search_strategies.md` for company research
   - Identify key contacts and champions
   - Plan LinkedIn outreach campaign

5. **Create Standout Application**
   - Reference `creative_applications.md` for unique approaches
   - Choose format based on company culture
   - Develop company-specific portfolio piece

6. **Prepare for Success**
   - Reference `interview_strategy.md` when interview scheduled
   - Prepare story bank and practice answers
   - Plan follow-up strategy

### Rapid Positioning for Urgent Applications

For opportunities requiring immediate action:

1. Run job posting analysis (5 minutes)
2. Quick skill match assessment (10 minutes)
3. Generate targeted cover letter using 90-day plan format (15 minutes)
4. Quick LinkedIn research for hiring manager (10 minutes)
5. Submit application with immediate follow-up plan (5 minutes)

### Creative Campaign for Dream Companies

When targeting specific companies without open positions:

1. Deep research using `search_strategies.md` techniques
2. Create value-first content strategy
3. Build relationships with multiple employees
4. Develop company-specific portfolio project
5. Execute multi-touch outreach campaign

## Important Notes

### Customization is Key
- Never use generic templates without customization
- Always incorporate company-specific research
- Tailor strategies to company culture and industry

### Ethics and Professionalism
- All strategies should be honest and authentic
- Creative doesn't mean deceptive
- Respect boundaries and don't be pushy
- Quality over quantity in applications

### Track and Iterate
- Monitor which strategies generate responses
- A/B test different approaches
- Adjust based on feedback and results
- Share wins to build momentum

### Timing Matters
- Submit applications Tuesday-Thursday mornings
- Follow up after one week
- Research company news for timely hooks
- Align outreach with company announcements

### The Human Element
- Technology and strategies are tools, not replacements for genuine connection
- Authentic enthusiasm beats perfect execution
- Cultural add is more valuable than culture fit
- Skills can be learned; attitude and potential matter more

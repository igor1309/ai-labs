Operating Flow

Dev Skills treats agent work as a sequence of scoped decisions. The same library can support lightweight discussion, strict implementation gates, or release work.

1. Orient

Replay context, intake the assignment, and separate exploration from implementation.

2. Shape

Turn intent into specs, ADRs, action plans, and executable test scaffolds.

3. Build

Run TDD, architecture checks, interface ownership rules, and platform-specific helpers.

4. Ship

Apply process gates, CI watch, release discipline, Docker checks, and documentation drift audits.

# Frontend ADRs

Architecture decisions scoped to the notio **frontend**. These ADRs form their own numbering namespace (`ADR-001`, `ADR-002`, ...) distinct from the capture-side ADRs under `notio/docs/adr/` (`adr-001-...`, `adr-002-...`).

Filenames use uppercase `ADR-NNN-...` to make the namespace visually distinct from the lowercase `adr-NNN-...` used by the capture-side ADRs. Cite as "frontend ADR-NNN" when the context is ambiguous.

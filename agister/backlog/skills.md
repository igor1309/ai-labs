# Skills

Left out of the first cut of settings (the owner, 2026-10-14). No
settings in `home/` use a skill yet.

## What is open

- **What a skill is.** A skill is a folder, `skills/<name>/SKILL.md` and
  the files beside it, not one file. Taken whole from the nearest layer,
  it is a set of files with one digest over all of them, or something
  else.
- **How layout reads it.** Every other kind is one file per name; a skill
  is a folder per name.
- **What a run is given.** A process and an agent name skills; how the
  runtime gets the files, and what the record keeps of them.

## When

When the first settings use a skill. By then it is known whether a skill
is one file or a folder.

## Where it lands

`docs/settings-implementation.md`: a skill is a blob of its own kind,
reached by name like a prompt or a schema.

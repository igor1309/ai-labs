Claude Insights

Weekly Claude Code usage reports from local session data, delivered through Supabase and Telegram.

Claude Insights turns local usage artifacts into a recurring engineering feedback loop: session volume, code churn, tools, goals, friction points, outcomes, and narrative summaries. The output is a compact report you can query later from Telegram.

~/.claude/usage-data source Supabase storage Telegram bot summaries

Core idea

Usage data becomes a weekly operating signal.

The project aggregates Claude Code session records, extracts the narrative parts of the local insights report, persists the snapshot, and sends a Telegram notification when a new weekly summary lands.

Input

Local session artifacts

Reads Claude usage facets and session metadata from the local machine, plus cached narrative sections from the insights report.

Store

Supabase snapshot history

Writes weekly summaries to a persistent table so reports can be fetched, compared, and retained over time.

Delivery

Telegram report surface

A bot posts new summaries and answers commands for the latest report and trend comparisons.

Pipeline

A small weekly path from disk to chat.

01

Collect

Aggregate local Claude Code usage JSON for a date window.

02

Summarize

Include narrative sections from the local insights HTML report.

03

Persist

Push the weekly JSON snapshot to the Supabase `claude_insights` table.

04

Notify

A database webhook calls the Edge Function that sends the Telegram message.

05

Compare

The bot can fetch stored snapshots and ask Nomos for trend analysis.

Metrics

The report tracks work shape, not just volume.

Claude Insights keeps quantitative counters and qualitative narrative in the same snapshot, so a weekly report can explain both what happened and where the workflow needs attention.

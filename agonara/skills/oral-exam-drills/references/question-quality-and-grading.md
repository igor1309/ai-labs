# Question quality and grading lessons from this session

## Durable lessons
- In oral drills, the prompt itself must not contain the answer map. Bullets like "what is the conflict / why is confidentiality limited / what should the psychologist do" can over-scaffold the response.
- If a student already answered a case, do not re-ask the same case in slightly different wording. Accept the answer, assess it, and move on.
- When a student says the case is underdetermined, check whether the case really lacks deciding facts. If yes, the right move is to concede the flaw and switch cases.
- Do not treat smoother assistant phrasing as semantically superior by default. Separate substance from rhetorical polish.

## Red flags for badly built oral questions
- Subpart B repeats the concept named in subpart A.
- The question presupposes the target answer in its own wording.
- The case mixes multiple variables so that the intended conclusion is not actually determined.
- The question asks for a judgment while withholding the facts that would make that judgment possible.

## Better pattern
- Give one concrete case.
- Ask one open question: "How would you analyze this by the logic of the course?"
- If follow-up is needed, ask it after the student answers, based on what they actually said.

## Grading rule
Default to: content first, precision second, polish third.
A semantically correct answer should not be downgraded just because the assistant can make it sound more elegant.

# User calibration notes for assistant-authored drills

Condensed lessons from a study-drill session.

## High-value preferences
- The user wants genuinely random correct-answer placement across a run; visible repetition (for example, many correct answers in slot 2) is irritating and should be corrected.
- The user wants hard distractors with no obviously weak throwaway options.
- The user values fine conceptual distinctions and will notice when several options are too easy to eliminate.
- The user often answers with both a choice and commentary; the commentary should be acknowledged.
- When the user requests a staged workflow (for example: recap, then topic summary, then questions, each only after "дальше"), obey the pacing strictly.

## Concrete repair pattern
When a question has weak distractors:
1. say the criticism is fair;
2. name the defect (too obvious, wrong conceptual level, weak competitors, etc.);
3. reissue a stronger version immediately;
4. keep the remaining block tighter.

## Topic-specific examples of good distinction work
- burnout vs ordinary fatigue
- burnout vs deformation
- deformation vs adaptation
- professional distance vs emotional detachment
- empathy vs fusion with the client
- possession of a personal difficulty vs inability to hold a professional position because of it

## Practical drafting note
For tricky questions, aim for 3 near-neighbor distractors rather than 1 correct option plus 3 obvious rejects.

## Two-contour failure episode (the reason the balance rule exists)
The user was prepared heavily on meaning — principles, dilemma/non-dilemma
distinctions, case analysis, code-of-ethics argument — and scored 71/100 on a real
test, losing points on the *nomenclature* layer: named classifications and author
typologies (Markov/Markova, Schwartz, and similar — who distinguished what, how the
scheme is named and built). The course tested the factual contour; the prep had
under-trained it. Correction the user asked for: not a separate cram block and not a
pure-logic block, but a **mixed run** that trains understanding and course fixtures
together, with per-answer feedback that names the *error type* (logic / fact /
adjacent-category confusion / unknown author-scheme). The canonical rule lives in the
SKILL body ("Two-contour balance"); this is the episode behind it.

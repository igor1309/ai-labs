# Agonara Positioning

## Anchor

Turn scattered study into structured progress.

Agonara is a BYOA learning program environment for serious self-directed learners and program curators.

Bring your own agent to shape sources into curated programs, connect materials and concepts, run checks, and keep progress grounded in evidence.

## Problem

Serious learning breaks down when materials, concepts, and proof of understanding live in separate piles. Agonara gives you a program-shaped workspace for turning that scatter into a path you can follow, revise, and verify.

## Curate, Follow, Verify

Build the program from selected sources. Move through it with checks and feedback. Keep progress grounded in evidence that belongs to the learner.

## Bring The Agent You Already Use

Point it at your Agonara instance and follow role-specific guidance for curating programs, learning through them, and managing the private instance.

The agent helps with the workflow. You remain responsible for accepted program content and how learning evidence is used.

## Human Acceptance Stays Central

Agents can help draft, evaluate, and carry out the workflow, but accepted program content remains a human decision.

## Durable Structure

Agonara helps people build and follow curated learning programs: sources are shaped into a program, concepts connect to materials, checks turn answers into feedback, and progress stays grounded in learner-owned evidence.

## Learners And Program Curators

### Learn Through A Program

Follow selected materials, concepts, checks, and feedback without losing the thread.

### Curate A Program

Shape sources into a program, connect concepts to materials, define checks, and accept what belongs.

## Private Instance Operation

Agonara is built for private, recoverable operation. Bootstrap an instance, manage identities and access, inspect audit events, and preserve program and learner state through backup and restore.

# FolioTell 0.6.2

## What's New

- Playback controls now use a single coordinator, so Play reaches speech
  immediately and controls no longer wait on queued state updates.
- Pause requested during speech startup is applied as soon as speech starts.
- Progress and saved listening position update from one live playback source,
  preventing stale callbacks from stopping a newer reading session.

# FolioTell 0.6.3

## What's New

- Stop now resets the reading position, so the next Play starts from the
  beginning of the document.
- Resume now uses a clear Play icon.
- Voice names in the picker are shorter and easier to scan.
- Opening an English document now selects an English voice instead of carrying
  a Russian voice from a previous document.

# FolioTell 0.5.0

## What's New

- Voice-quality onboarding now guides readers to install higher-quality Apple
  voices when only standard voices are available.
- The reader acknowledges installed Enhanced or Premium voices and labels
  higher-quality choices in the voice picker.
- Automatic voice selection now prefers the highest-quality audio-capable
  voice for the document language.

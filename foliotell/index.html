FolioTell

Hear your documents, straight from the file browser.

A native document-to-speech iPhone app. Open a local Markdown or plain-text file from the system document browser and listen to it with Apple speech synthesis — offline, read-only, no account. Working name; v0.0.1 is implemented as a Swift package.

Product shape

Document-oriented, spoken, and local

A small, native SwiftUI app built on DocumentGroup(viewing:) and a FileDocument — no backend behind it.

Reader

Document-first

Opening a document immediately presents the reader; closing it returns to the same browser folder.

Speech

Apple synthesis

System voices via AVSpeechUtterance. Selected speed persists across launches with AppStorage.

State

Idle · speaking · paused

A small explicit state machine over document, selected speed, playback state, and error — with concise error messaging.

Naming · in validation

Working name among close candidates

FolioTell is the current working name — folio (a document collection) plus tell (spoken delivery). Comparative working scores against the naming brief:

89 · leading

Sayfold

Compact and immediately pronounceable; document meaning is metaphorical and may need a subtitle.

87 · working name

FolioTell

Strong built-in document semantics and format-neutral; slightly literary and four syllables.

83

Verbatone

Polished and memorable, but existing audio-product usage creates search and brand friction.

Deliberately not

What FolioTell refuses to be

Scope is held tight on purpose — these are v0.0.1 constraints, not a roadmap.

no account no backend no analytics no subscription no network dependency read-only access not a read-later app not an audiobook / podcast app

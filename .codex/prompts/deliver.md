Deliver the current change by delegating its implementation and review.

The rules are in `.claude/skills/deliver/SKILL.md`, the one source for
Claude Code and Codex sessions alike. Read it there; do not work from a
copy.

1. Read `.claude/skills/deliver/SKILL.md`.
2. Find the part for the directory the change is in: a project's part
   replaces the default there.
3. Follow that part: implement, verify the result yourself, review, rule
   on the findings, within its number of review rounds.
4. Report what was delivered, the checks with their results, and any
   step that was blocked.

## Definition of Done

- The skill's part for the change's directory was followed.
- The result was verified by this session, not taken from the
  implementer's report.
- If any step is blocked, the reason is reported and no later step is
  attempted.

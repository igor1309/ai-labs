# Warder — Name Brief

**Status:** Selected working name  
**Product category:** Local AI-agent execution monitoring  
**CLI name:** `warder`  
**Availability:** Blocked under the current naming standard

## Name rationale

**Warder** is a traditional term for a guard, keeper, or watchman entrusted with overseeing a place or its occupants.

The name expresses the product's primary responsibility: maintaining visibility over locally running AI agents, their execution states, and progress.

It belongs to the same occupational naming family as **Agister** and **Hayward**.

## Product positioning

*A local monitor for AI-agent runs.*

Warder provides a central place to observe running agents and their execution activity, including agents participating in multi-stage or parallel workflows.

## Alternative Names Considered

Listed in original shortlist order.

1. **Runfold** — An enclosure for agent runs. Suggests one place to observe concurrent work, with a subtle pastoral connection.

2. **Eaves** — Suggests listening in on agent execution and observing events as they happen. Compact and distinctive.

3. **Rundown** — A live rundown of every agent's status, progress, and outstanding work. Familiar word with an immediate product connection.

4. **Runbell** — A signal for run completions, failures, and requests for intervention.

5. **Yarder** — A forestry machine or worker that moves logs. Connects the rural naming theme with execution logs.

6. **Stile** — A passage through a fence. Suggests tracking agents as they move between workflow stages.

7. **Runpost** — A lookout post for ongoing runs. Conveys continuous local observation.

8. **Runmark** — Records execution milestones, state transitions, and completion markers.

9. **Knoll** — A small elevated hill providing a vantage point. Fits the rural vocabulary of the existing tools.

10. **Logfold** — Collects logs and events from multiple agents into a single coherent view.

11. **Runkeep** — A keeper of running processes, retaining their status and execution history.

12. **Waypost** — A marker along a route. Suggests visibility into each agent's progress through a workflow.

13. **Runrack** — An orderly arrangement of active runs, suitable for a compact terminal status dashboard.

14. **Runlamp** — Illuminates active runs and highlights those needing attention.

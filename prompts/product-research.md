Research Prompt: Existing Company Product

Input

Company: [Company]
Product: [Product]
Product family: [Product family, optional]
Use case / workflow: [Use case / workflow, optional]

Task

Research the current public state of [Product] by [Company].

If [Product family] is provided, include only that explicitly named family. Keep scope limited to the named product and explicitly provided family.

Research focus

Cover:

1. Product overview
    * what the product is;
    * who uses it in practice;
    * what professional workflow it supports;
    * what concrete jobs it performs.
2. Core capabilities
    * main functions;
    * user-facing features;
    * automation features;
    * collaboration or handoff features;
    * import/export capabilities.
3. Workflow map
    * typical user roles;
    * entry point into the workflow;
    * main steps;
    * outputs;
    * handoffs between users/systems;
    * permissions or access-control signals.
4. Technical/workflow surface
    * integrations;
    * APIs;
    * webhooks, if publicly documented;
    * supported platforms;
    * data import/export;
    * admin controls;
    * security/compliance docs only when directly relevant to product use.
5. Recent changes
    * meaningful product changes from the last 6–12 months;
    * fresh docs, changelog entries, product updates, release notes, help-center updates, or customer-use signals.

Sources to use

Use public evidence from:

* official website;
* product pages;
* documentation;
* help center;
* changelog;
* product blog / release notes;
* API docs;
* customer stories;
* practitioner reviews;
* forums or user discussions.

Cite sources for factual claims.

Evidence handling

Stay evidence-only:

* collect facts;
* structure them;
* cite them;
* flag stale evidence;
* flag missing evidence.

When a claim is unsupported, mark it as evidence missing.

When a source appears outdated or deprecated, mark it as stale evidence.

Ignore these topics

* pricing;
* positioning;
* GTM;
* sales motion;
* marketing-claim analysis;
* funding;
* investors;
* market size;
* competitors;
* ethical commentary;
* editorial commentary;
* generic AI discussion.

Output format

Produce a concise structured report:

1. Product overview
2. Core capabilities
3. Workflow map
4. Technical/workflow notes
5. Integrations and platform signals
6. Recent product changes: last 6–12 months
7. Stale or missing evidence
8. Source appendix

Keep prose tight. Use tables where they reduce length. Avoid speculation.

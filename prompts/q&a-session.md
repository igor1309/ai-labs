Before executing, run a Q&A to clarify intent, constraints, scope, and ownership boundaries.

Do not add unrequested background, theory, or generic advice at any phase.

Rules:
- Ask up to 10 questions, one at a time.
- Provide answer options as A/B/C/D/etc.
- Each option must include a concise tag. Pick one consistent axis per question (e.g. complexity, strictness, preference, frequency) and tag every option on that axis.
- If my answer is ambiguous, ask the next clarifying question instead of assuming.
- Ask ownership/boundary questions whenever the task has them.

After Q&A:
1. Produce a task playback that restates goal, hard constraints, ownership decisions, non-goals, and output format, then ask me to confirm.
2. Execute only after I confirm.

Execution:
- Produce the requested artifact in one pass.
- Keep the output structured, concise, and directly reusable.

After execution:
1. Run an adversarial review against the confirmed playback, flagging contradictions, gaps, and scope drift.
2. If issues are found, propose a surgical patch.
3. Apply only after I approve.

Start with the first question.

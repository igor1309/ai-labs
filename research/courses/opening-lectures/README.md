# Opening lectures — three programs

> Internal codename: **Kiora**.

Draft structures for the **first lecture** of each of the three prospective
programs. This is **ground for discussion**, not a launch decision, a topic
freeze, or a commitment to any one program — all three are held in parallel.

## The three programs

| # | Program | Audience | Object of practice |
|---|---|---|---|
| 1 | Интернет-предприниматели с IT-бэкграундом | technically-literate internet founders | ship a real product / business |
| 2 | Программисты — прокачать кодинг с AI | working developers | their own code / dev workflow |
| 3 | Служащие / обыватели | non-technical professionals | their own everyday work routine |

Each program is a different **object of practice** — three products sharing one
format, not three cohorts of one course. See `../positioning-notes.md` for how
these map onto the surveyed competitor slots, and `../market-2026/` for the
market + demand research behind them.

## Format principles (established this session)

1. **Demonstration, not prescription** — *"look, this is how it could be done,"* shown by doing it. Not *"here's how you should work."*
2. **No acting, no staged emotion, no faked naïveté** — the two on camera are practitioners, not actors. The value is real work actually getting done. Genuine questions between competent peers are the Socratic engine; performance is not.
3. **Mid-2026 audience level** — everyone is already AI-aware and has dabbled. The dead premise is "what is AI / first contact." The wedge is **grounded work on real, everyday problems.**
4. **Tool access / VPN / payment is a webinar topic, not lecture content** — lectures use whatever is accessible and good (Chinese DeepSeek/Qwen and local YandexGPT/GigaChat cover the no-VPN path).

## The shared hidden shape

Every opening lecture's questions follow the same arc, so the three rhyme
without repeating:

**provocation → mechanism → the shift → judgment / verification → honest limit**

Each question is answerable by *doing*, not lecturing — and phrasing the
top-level topics as questions is what sets the Socratic expectation.

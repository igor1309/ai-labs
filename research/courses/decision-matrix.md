# Course decision matrix

## Status

First-draft inventory of the **angles** along which a course concept needs to be decided. This is not the course; it is the question-space.

No commitments. Each angle lists candidate answers/options to evaluate, not a chosen direction.

A JTBD reframing pass is planned next (see `dev-skills:jtbd`) and may restructure or replace this layout.

Who could plausibly want this? Who would I want to teach?
- Solo founders / indie hackers shipping products
- Working developers adding AI to existing stacks
- Engineering managers / tech leads evaluating AI tooling for teams
- Career-switchers entering software via AI-assisted coding
- Students / hobbyists exploring AI coding
- Domain experts (non-developers) who want to ship software via AI tooling

- Both (which one first?)

### Geography / market

- Specific stack: agents, MCP, tool-use, prompting for code
- Software engineering discipline *with* AI (TDD, review, architecture under AI)
- Something else not yet named

### Level
- Beginner
- Intermediate
- Advanced
- Mixed-level (with branching paths)

### Prerequisites
- None

- Membership in a community / network
- Hiring readiness for AI-coding roles

# CareerFactory Vibe-Coding Course Curriculum

## Curriculum Goal

Take a non-developer from zero to a self-built, deployed application by teaching them to direct AI tools through a real software-development workflow — Git, professional tooling, product architecture, AI integration, and deployment — without first learning a programming language by hand.

## Target Student

The curriculum is designed for motivated non-developers:

- Primary: people with no programming background who want to build their own products.
- Secondary: aspiring founders who need a working prototype, and professionals worried their skills will be displaced by AI.
- Not required: any formal IT education or prior experience.
- Required disposition: willingness and persistence to investigate unclear things by asking the LLM or peers, and tolerance for reading (not writing) code.

## Learning Outcomes

By the end of the course, students should be able to:

- Use Git, GitHub, Cursor, and Docker as part of a normal development workflow.
- Understand the building blocks of an IT product: frontend, backend, database, and API.
- Build a working Telegram bot with an admin panel that stores user data safely.
- Integrate an LLM into an application, write effective prompts, and control token costs.
- Add memory and tool-calling so an AI agent can act on databases and run commands.
- Deploy an application to a VPS with a domain and keep it running 24/7.
- Practice digital security hygiene — protecting API keys and passwords while working with AI tools.
- Maintain a project using practices drawn from real IT companies.

## Practical Spine

Students build a single Telegram bot across all 8 weeks, growing it from a first project into an AI-powered, deployed product:

- Environment setup and first project.
- Product architecture and a first bot with an admin panel.
- LLM integration, memory, and tool-calling.
- Deployment, scaling, and maintenance.

The course is delivered as two live webinars per week (Mondays and Wednesdays, 18:00 MSK, ~2 hours each) with recordings, and a practical homework assignment each week. A starter template and graded assignments (simple to complex) lower the barrier to starting.

## Block Curriculum

### Weeks 1-2: Git and Launching the First Project

Purpose:

- Set up a professional development environment and ship a first running project.

Topics:

- Git fundamentals: commits, branches, GitHub.
- Professional tooling: Cursor, Docker, tunnels.
- Running a project with hot reload.
- Reading logs.

Practice:

- Configure the local toolchain.
- Launch a first working project and push it to a personal GitHub profile.

Deliverable:

- A fully configured development environment and a first working project visible in the student's GitHub profile.

### Weeks 3-4: Architecture and the First Telegram Bot

Purpose:

- Understand how IT products are structured and build a first real bot.

Topics:

- Product architecture: frontend, backend, database, API.
- Building a Telegram bot with an admin panel.
- Digital security: protecting API keys and passwords.

Practice:

- Create a working bot with an admin panel.
- Apply secure handling of secrets and user data.

Deliverable:

- A working Telegram bot with an admin panel that safely stores user data.

### Weeks 5-6: AI Integrations and Smart Functionality

Purpose:

- Make the bot intelligent by integrating an LLM and giving it agentic capabilities.

Topics:

- Connecting an LLM to the application.
- Prompt writing.
- Controlling token spending.
- Adding memory.
- Tool-calling against databases and commands.

Practice:

- Integrate an LLM into the bot.
- Add context memory and tool-calling for real task automation.

Deliverable:

- An intelligent AI bot that remembers context and can automate real tasks.

### Weeks 7-8: Deploy and Scaling

Purpose:

- Put the product into production and learn to keep it healthy.

Topics:

- Deploying to a VPS.
- Domain setup.
- Running 24/7.
- Advanced vibe-coding techniques.
- Project maintenance practices from real IT companies.

Practice:

- Deploy the bot to a real server with a domain.
- Operate it continuously and apply maintenance practices.

Deliverable:

- A finished product running on the internet 24/7, plus the skills to build new projects.

## Capstone

The capstone is the deployed Telegram bot itself: a self-built, AI-integrated application that runs 24/7 on a VPS, demonstrating the full path from environment setup through architecture, AI integration, and deployment.

## Recommended Student Artifacts

- Configured GitHub profile with the first project.
- Telegram bot repository with admin panel and secure secret handling.
- Prompt set and token-cost notes for the LLM integration.
- Memory and tool-calling configuration for the agent.
- VPS deployment with domain and 24/7 operation.
- Maintenance notes following real-company practices.

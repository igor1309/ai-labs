# Kiora — course initiative (research)

Internal codename **Kiora**. Research and discussion ground for a prospective
AI-teaching initiative. Everything here is **inputs, not commitments** — no launch
decision, no frozen topics.

## What it is (as explored so far)

- **Three programs** (three distinct objects of practice, one shared format):
  1. Интернет-предприниматели с IT-бэкграундом — ship a real product/business.
  2. Программисты — прокачать кодинг с AI (adopt AI into existing dev work, no career pivot).
  3. Служащие / обыватели — solve everyday routine tasks with AI.
- **Two markets:** Global / English + Russian / CIS.
- **Format:** recorded two-person Socratic **demonstration** ("look, this is how it
  could be done" — real work done, no acting) + live webinars.

## Design principles (established, still revisable)

1. Demonstration, not prescription. 2. No acting / no faked naïveté — genuine peer
inquiry is the Socratic engine. 3. Mid-2026 audience level — everyone is AI-aware;
the wedge is grounded work on real problems. 4. Tool access / VPN / payment is a
**webinar** topic, not lecture content.

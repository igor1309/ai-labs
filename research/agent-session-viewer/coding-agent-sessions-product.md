# Локальный центр для работы с сессиями coding agents

Собирает в одном интерфейсе сессии разных агентов --- Claude Code,
Codex, Pi, позже OpenCode и других --- и даёт единое представление
текущей и прошлой работы: что происходит сейчас, где требуется внимание
и к какому контексту можно вернуться.

Сессии можно искать, фильтровать, группировать и просматривать вместе с
их историей и контекстом проекта.

## Этапы

### MVP · Mac

Read-only:

-   обнаружение сессий;
-   live-состояние;
-   история и transcript;
-   поиск;
-   навигация.

### V2 · iPhone

Тот же read-only доступ к сессиям на своём Mac с мобильным UX.

### Дальше

Взаимодействие с локальными runtime:

-   reply;
-   approvals;
-   resume/new session;
-   уведомления;
-   handoff между агентами;
-   автоматизация.

Ядро продукта --- единое пространство для работы с локальными agent
sessions. Read-only --- свойство первых версий, а не определение
продукта.

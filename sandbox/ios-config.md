# iOS Config

iOS Config is added to worktree folder as symlink and gitignored.

Feature dev folders contain links (Jira, Figma, FigJam), prompts, plans, specs, JSON response samples, screenshots, screencasts, etc. Currently live in `iFora/Features/`.

How about moving feature dev folders into iOS Config repo?

## PRO
- One less separate folder to reference.
- Version control.

## CONTRA
- The only downside I could imagine is screencasts that are heavy. Everything else is lightweight.

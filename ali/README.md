# AI Learning Agent — Project Notes

> **Status:** Exploration / registered participant (as of 2026-10-25)  
> **Working name:** ALI (Adaptive Learning Intelligence) — suggested during discussion, **not approved as the final name**  
> **Competition track under consideration:** Best Societal AI Agent — education

## Purpose

Explore a personalized, lifelong-learning AI agent that can help learners of different ages and backgrounds understand material, develop learning skills, and make progress toward goals they define.

The proposed system would combine an autonomous learning coach, adaptive teaching strategies, and a persistent **Personal Learning Twin**. This is a concept, not an implemented or validated system.

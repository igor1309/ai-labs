# nomos

LLM access control proxy.

## Description

A unified proxy between projects and LLM providers — vendor abstraction, per-project budget limits, token usage logging, and basic prompt injection safeguards. *No cloud vendor lock-in*, just a single Docker service with SQLite.

## Stack

- Node.js
- Express
- SQLite
- Docker
- Caddy
- VPS
